Nasi goreng — Indonesian fried rice, wok-fired and golden, with a sunny-side-up egg, crispy krupuk, cucumber, tomato and sambal, steaming on a wooden table.

## Run it

```sh
python3 main.py
```

It copies the entry image from the repository to `$MAKEFUN_OUTPUT_DIR/entry.png` (else `/output/entry.png`). Python 3.13, standard library only, no network, deterministic.
